# Local paper archive

Cutoff date: **2026-08-17 (Asia/Shanghai)**.

This archive supports the RouteCraft research-decision report. Files are grouped by their role in the review, not by an assertion that every item is a direct full-model Agent Router.

- `00_background/`: unpublished local background manuscript; methodology seed only.
- `01_model_routing/`: complete-model query/prompt routing and routing benchmarks.
- `02_agent_routing/`: multi-turn, agentic, harness-native, escalation, or workflow-adjacent routing.
- `03_harness_systems/`: harness and serving-system papers or documentation snapshots when distributable.
- `04_trajectory_distillation/`: trajectory, plan, tool-use, failure, and recovery learning.
- `05_theory_methods/`: options/SMDP, deliberation cost, information bottleneck, state abstraction, and off-policy evaluation.
- `06_benchmarks/`: benchmark papers used to scope tasks and verifiers.
- `07_latency_time_cost/`: request latency, tail/SLO, queueing, prefix/KV locality, and Agent-program execution-time papers used for the time-cost audit.

Important qualification: a local PDF is a convenience copy for research. Publication status, official code, authorship, and claims must be taken from the source registry and the cited primary source, not inferred from the filename. Preprints remain labeled as preprints. A zero-byte or missing file is a failed retrieval, not a verified paper.
